# 电脑可视化前端

电脑入口为本地浏览器页面，服务只绑定 127.0.0.1:8765，使用现有真实 Silero/Vosk/MiniLM 模块。它与手机局域网网关分别运行；电脑前端不对手机开放，也不需要发布到公网。

## 打开

当前电脑双击 outputs/打开电脑界面.cmd，或原 Start-Desktop.cmd，都会自动启动后台本地服务并打开默认浏览器。页面地址 http://127.0.0.1:8765。保留整个 work 与 outputs 目录；不是仅复制 HTML 就能运行的静态演示。

先点击“没有音频？试试合成语音示例”，再点击“开始分析”即可体验。不必准备录音。示例明确标记为系统合成语音。自己的音频通过“选择音频文件”或拖放导入，格式仍为 16 kHz、单声道、16 位 PCM WAV，时长 0–60 秒；不会静默重采样。

页面可编辑参考要点、预听 WAV、观察加载和 M1–M4 阶段、取消任务、查看完整转写、要点覆盖/可能遗漏、依据句、节点耗时、模型版本，下载 Markdown 和 JSON。本次服务会话保留最近 30 个任务入口，完成后可重新查看。重启服务后页面会话列表重置，自动保存的结果文件仍在 outputs/Desktop-Web-Results。

首次真实模型加载约一分钟，后续任务复用已加载模型。取消不会强行打断原生模型线程，而是在当前调用返回后丢弃结果；等待结束后才能提交下一次分析。系统拒绝重复并发任务。

双击 outputs/关闭电脑界面.cmd 可关闭本界面后台服务；仅关闭浏览器页签不卸载模型。再次双击打开会重启。关闭脚本核对 PID 与本任务的启动命令，避免误关其他程序。端口被无关程序占用时明确失败，不冒充运行成功。启动日志在 work/desktop-ui-runtime。

## 源码与复跑

server/desktop/app.py：任务状态、原始 WAV 解析、真实模块加载复用、结果导出与本机 API。server/desktop/static/：无外部 CDN 依赖的 HTML/CSS/JS。server/desktop/launch.py：本地启动/浏览器/PID 文件。依赖沿用 requirements-team.lock，无需新下载前端构建工具。

在仓库根目录：

    python -m server.desktop.launch --models models --output <结果目录> --sample <合成诊断WAV路径>

前端 API 有页面会话凭据和同源核对，凭据不写日志；默认无访问正文日志。任务临时 WAV 处理后清理，结果文件按用户请求包含转写和证据。文件与要点通过 DOM textContent 展示。

## 实际验证

浏览器实际点击示例并运行真实权重成功：转写和匹配与固定电脑金样例一致，分数差在 1e-6 内；下载 JSON 与实际结果一致。展开节点耗时、未选音频提示及窄屏/1280px 双栏布局已检查。浏览器截图及 JSON、自动化测试日志见 .evidence/desktop-ui/。

5 项新界面后端测试覆盖：本机/同源/会话校验、错误输入、任务进度与结果下载、模型复用、单任务约束、取消迟到结果以及缺模型提示。连同既有测试共 34 项通过。测试中的 fixture 与真实模型浏览器记录分别标记，不冒充手机实测。

电脑前端是辅助使用入口，不等于手机采集或正式质量评价。手机实测从确认 Android 型号/系统/剩余存储、传入 APK 与模型包、安装导入、离线固定样例开始，由用户逐步操作并记录实际结果。没有数据线可后续用同一局域网传文件，无需先连接 ADB。
