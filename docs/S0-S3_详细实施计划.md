## 2. 契约先行（S0 必须先完成，未评审通过不进入编码）

契约不是某一人的文档：**林负责 schema 与错误表，刘确认 M0/M1/M5 字段，彭确认 M2–M4 与模型字段；三方在同一份样例上签字。**

### 2.1 模块契约（M0–M5）


| 模块 | 输入                                           | 输出                                                                                                | 必须写死的约束                                                                                | 错误                                                          |
| ---- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| M0   | 麦克风或导入 WAV、题目 ID                      | `audio{sample_rate_hz:16000,channels:1,sample_format:"s16le",sample_count,pcm_b64}`                 | WAV 头不进载荷；解码字节数 =`sample_count×2`；左闭右开                                       | 坏文件/超限 →`INVALID_PAYLOAD`；无权限可导入                 |
| M1   | `audio`                                        | `segments[]{segment_id,start_sample,end_sample,pcm_b64}`                                            | 起点升序、不重叠；PCM 字节数 = 区间长度×2；时间用原始采样索引                                | 纯静音 →`NO_SPEECH`                                          |
| M2   | `segments[]`                                   | `transcript{full_text,segments[]{segment_id,start_sample,end_sample,text}}`                         | 保留原时间坐标；段文本为空也保留段；`full_text` 段间分隔符由 schema 定一种                    | 有语音无转写 →`NO_TRANSCRIPT`；缺模型 → `MODEL_UNAVAILABLE` |
| M3   | `transcript` + `keypoints[]{keypoint_id,text}` | `embeddings{dimension,answer_sentences[]{sentence_id,text,vector},keypoints[]{keypoint_id,vector}}` | 384 维；`max_length=128`；mean pooling；L2 归一化；`sentence_id` 与原文顺序稳定对应；空句丢弃 | 维度/向量非法 →`INVALID_PAYLOAD`                             |
| M4   | `embeddings` + 版本化匹配配置                  | `matches[]{keypoint_id,score,covered,evidence_sentence_id,evidence_text}`                           | 余弦；并列取输入顺序最早句；零向量/维度不符按无效，不伪造分数；阈值从配置读                   | 零向量 →`INVALID_PAYLOAD` 诊断                               |
| M5   | `transcript`、`matches`、任务终态、摘要指标    | 页面与本地保存结果                                                                                  | 以`task_id` 关联；同一任务只采纳一次；取消后忽略迟到结果                                      | 按任务状态机                                                  |

补充约定（三人共同遵守）：

1. 所有时间戳取原始录音采样索引，区间左闭右开；
2. JSON 一律 UTF-8，数值必须有限（拒绝 NaN/Inf）；
3. 本地执行传类型化对象，远程才序列化；
4. 模块不得读 UI 状态、改计划、自行切执行端；
5. 向量维度、阈值、max_length 从 `models/manifest.json` 或 `config_version` 读取，不写死在代码。

### 2.2 HTTP v1


| 项       | 约定                                                                                                                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 探活     | `GET /healthz` 返回服务版本、协议版本、可用模块；缺模型模块标不可用                                                                                                                                                                                                             |
| 执行     | `POST /api/v1/modules/{module_id}/execute`，只接 M1–M4，一次一个模块                                                                                                                                                                                                           |
| 请求信封 | `schema_version, task_id, attempt, module_id, plan_version, model_version, config_version, remaining_budget_ms, payload`                                                                                                                                                        |
| 成功响应 | 回显上述版本字段 +`status:"OK"` + `executor:"REMOTE"` + `elapsed_ms` + `output`                                                                                                                                                                                                 |
| 错误响应 | 同信封 +`status:"ERROR"` + `error{code,message}`                                                                                                                                                                                                                                |
| 错误码   | 400`INVALID_PAYLOAD`；409 `VERSION_MISMATCH` / `IN_PROGRESS` / `REQUEST_CONFLICT`；413 `PAYLOAD_TOO_LARGE`；401 `UNAUTHORIZED`；404 `UNKNOWN_MODULE`；422 `NO_SPEECH` / `NO_TRANSCRIPT`；503 `MODEL_UNAVAILABLE` / `BUSY`；504 `DEADLINE_EXCEEDED`；手机侧 `REMOTE_UNREACHABLE` |
| 上限     | 60 s 音频、单请求 4 MiB、单设备一个在途任务                                                                                                                                                                                                                                     |
| 去重键   | `task_id + attempt + plan_version + module_id`；同键同内容已完成可回缓存，执行中 409 `IN_PROGRESS`，同键异内容 409 `REQUEST_CONFLICT`                                                                                                                                           |
| 安全     | 凭据不入日志；拒绝任意模块名、文件路径、无限载荷                                                                                                                                                                                                                                |

### 2.3 样例与签收


| 样例           | 提供人 | 内容                                                  | 签收                       |
| -------------- | ------ | ----------------------------------------------------- | -------------------------- |
| WAV + M1 片段  | 刘     | 16 kHz/mono/s16le WAV、哈希、`sample_count`、片段起止 | 彭独立解码，确认字节数吻合 |
| M2 成功/失败   | 彭     | 固定片段 → transcript；`NO_TRANSCRIPT`；缺模型       | 林过 schema，刘在手机复跑  |
| M3 金样例      | 彭     | token IDs、shape、向量前 8 维、norm、cos、容差        | 刘手机、林电脑各跑一次     |
| M4 样例        | 彭     | 阈值 0.5/0.8 两组、并列句、零向量                     | 林核对信封，刘核对 UI 展示 |
| 请求/响应/错误 | 林     | 成功、缺字段、错版本、超限、重发、超时                | 刘验客户端解码，彭核载荷   |

样例统一字段：`sample_id`、`input_sha256`、`schema_version`、`model_version`、`config_version`、`expected`、`tolerance`、`generated_at`、`generated_by`。

### 2.4 契约变更流程

1. 提出人写清影响面（生产方/消费方/字段/版本）；
2. 林改 schema 与样例，同一批次更新；
3. 刘、彭用成功 + 坏输入 + 超时三类用例复核；
4. 不兼容变更升 `schema_version`；已采数据保留原版本，修订后重跑受影响对照。

## 8. 联调顺序（最短链路优先）

1. 固定 WAV → 彭 M2 单测（不接 UI、不接麦克风）；
2. 刘 M1 片段 → 彭 M2（核对偏移与末段）；
3. 手机离线闭环 M0–M5（LOCAL）；
4. 手机调用电脑单模块（先 M2）；
5. 扩展到 M1、M3、M4；
6. 手动混合（至少跨端一次）；
7. 冻结 HTTP v1 与样例版本，交 S4。

每一步先产出可检查的 JSON 或文件，再接下游；失败回到最近可运行提交。

## 9. 证据规范

每条记录至少含：用例编号、提交号（APK/服务）、设备 ID、模型/配置版本、输入样本或请求、预期与实际、通过状态、证据路径、复核人。

- 模型：`models/manifest.json` 的 SHA256；
- 构建：APK 版本、Gradle/JDK/SDK；
- 服务：提交号、启动命令、端口；
- 日志：按 `task_id/attempt` 关联，脱敏，默认不导出原始音频与转写全文。

## 10. 风险与故障分派


| 症状                               | 第一处理人 | 协查                                 |
| ---------------------------------- | ---------- | ------------------------------------ |
| 录音空白、WAV 长度错、片段偏移异常 | 刘         | 彭用同一输入复核 M2                  |
| 同输入转写/向量不同、覆盖偏差      | 彭         | 刘确认 PCM 与片段哈希；林核模型版本  |
| 本地可跑、远程超时或解码失败       | 林         | 刘手机复现；彭绕过网络复核算法       |
| 计划与实际执行端不一致、重复回包   | 林         | 刘核客户端事件；彭核恢复后输入输出   |
| 统计图与原始日志对不上             | 林         | 原始记录提交人复核条件与异常纳入规则 |

主要风险与回退：


| 风险                                   | 回退                                       |
| -------------------------------------- | ------------------------------------------ |
| 多语言模型 448 MB 手机内存吃紧         | 换 int8 量化版，先测同输入向量差并写入容差 |
| Android ORT 与 Python ORT 数值差超容差 | 记录版本差异，按实测放宽并写入偏差单       |
| Vosk CER 偏高                          | 记录未达标；评估替换模型，重跑金样例       |
| WAV 采样参数不一致                     | 拒绝样本退回刘重导，不自行重采样           |
| 契约被改                               | 以 schema 为准，更新样例并重跑受影响对照   |
