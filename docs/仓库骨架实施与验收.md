# 仓库骨架实施与验收

本次按三人实施计划建立目录，三人可从 Android、语音与语义、端云执行与切分各自的入口开始准备 S0。仓库骨架包含模块和测试目录、契约、模型清单位置、实验材料位置以及架构文档位置。

README 是启动索引。environment.yml 是项目专用 Conda 环境的 Python 起点。现阶段入口用于定位工作和交接，运行时入口及模型依赖由 S0 建立。三方在 contracts/examples/ 交接音频格式、期望输出和协议样例。

首次发布前，按根 README 检查候选文件。骨架的验收口径为目录可纳入 Git、课程材料和本地证据被忽略、源码和服务实现状态标注准确。S0 还需验证两台手机的最小构建、三设备模型调用及最小请求。

已用临时 Git 元数据枚举工作区候选文件，共 38 项，七个主目录均可纳入。课程 Word 材料、内部实施计划与过程证据未出现在候选清单中。另用 Git 的忽略检查确认模型权重、录音、原始结果、Android SDK 本机配置及环境变量文件命中规则。检查由本次编制代理完成，首次正式提交仍以实际暂存清单为准。正式仓库初始化、提交和推送待提供远端地址。
