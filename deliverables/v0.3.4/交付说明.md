### 两个 APK 版本的区别

| 版本 | 大小 | SHA-256 | 能否跑 FORMAL 模式 |
|---|---|---|---|
| 本目录 `…-bc10024-debug.apk` | 30,515,604 B | `A06489DD…0F82417` | **能** |
| 最初交付包内的 `InterviewFeedback-0.3.4-debug.apk` | 30,514,911 B | `0044DC73…973B27A` | 不能 |

差异原因：App 的 FORMAL 模式要求 `apkCommit` 匹配 `[0-9a-f]{40,64}`，而默认构建的 `BuildConfig.SOURCE_REVISION` 是 `UNVERSIONED`。本目录这份是用 `-PsourceRevision=bc1002476144d75932d7936bf0fa106ff1f0d3de` 重编的，`SOURCE_REVISION` 为完整 40 位哈希，因此能通过校验。

模型包结构（已核对）：`manifest.json` + `weights/` 下 25 个文件，共 26 个条目。`manifest.json` 关键字段：`model_version = modelset-e8f8c211226b-066409f3d9db-9ba59cbaae79`、`config_version = rules-v2`、`config.dimension = 384`、`config.match_threshold = 0.54`、`config.vad_threshold = 0.5`。

APK 关键信息（已核对）：`com.example.interviewfeedback`、versionCode 8、versionName 0.3.4、minSdk 26、targetSdk 31、`native-code: arm64-v8a`、应用名「语音回答反馈」、入口 `ui.MainActivity`。

## 2. 快速开始

### 2.1 装机

```powershell
adb install -r .\InterviewFeedback-0.3.4-bc10024-debug.apk
```

### 2.2 导入模型

1. 把 `android-models-rulesv2.zip` 推到手机（模型包需另行获取，见 `README.md`）：

```powershell
adb push .\android-models-rulesv2.zip /sdcard/
```

2. 打开 App →「模型管理」→ 选择该 ZIP → 等待解压（约 192 MB 时状态条会提示，保持应用在前台）。
3. 成功标志：状态条显示「模型导入成功，文件已校验」。

### 2.3 运行

- **LOCAL**：直接点「开始录音」或「选择 WAV 文件分析」，全程手机本地推理。
- **REMOTE**：需先在「运行方式」栏填写电脑地址（同一局域网，形如 `10.x.x.x:8000`）与凭据，再选 REMOTE。
- **MANUAL_MIXED**：同一栏填地址与凭据后选混合模式，M2（ASR）与 M3（编码）走电脑，其余本地。

> 走 FORMAL 留档（导入 run 配置 + 样本清单）时，还需要先把配置与清单注入 App 私有目录并切 `active_run` / `active_samples`，步骤见 `S3_三模式对照报告_20261115.md` §8.1。

## 6. 已知限制

| 项 | 说明 | 影响 |
|---|---|---|
| 两机验收未完成 | 全程只在一台 ELI-AN00（`AQULVB4522044827`）上验证 | S0-T1/T2、S1 两机维度、S2-T1 均未达标 |
| 有效输入仅 30/100 | S2-T1 要求 ≥100 次，当前 30 段 | 统计置信度不足 |
| 提示词照稿朗读 | 30 段录音为照稿朗读，故转写与参考文本重合度高 | CER 4.73% 不能代表自由口语场景 |
| 证据准确率 0% | 标注中 `accepted_evidence_sentence_ids` 未填 | S2 的 `evidence_accuracy` 指标无效 |
| 复核为口头确认 | 复核人在场听音并口头确认，未留独立书面记录 | `consent_evidence` 只有一段 provenance 字符串，无签字件 |
| 混合模式收益有限 | M2（ASR）占墙钟 93% 以上，无论切到哪里耗时都相近；混合模式主要省的是字节，不是时间 | 部署选型应关注带宽而非延迟 |
| 向量走 JSON 文本 | 384 维 float 以十进制字符串传输，约 13,624 B/向量 | 有压缩空间，本轮未做 |
| 手机侧 PCM 字节偏差 | 手机 M1 上传比桌面多 65,457 B，M2 多 65,194 B | 成因未定位，见 S3 报告 §5.4 |
| MIXED 重复跑差 5,014 ms | `8aa3dec0` 10,084 ms vs `da8343ba` 5,070 ms | 仅 409 ms 可归因到模块，其余未定位 |
